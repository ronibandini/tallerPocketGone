# Qué es Pocket Gone 
Pocket Gone es una herramienta de diagnóstico para parlantes Bluetooth que incluye un modo de silenciamiento (el cual solo debe ser utilizado con parlantes propios y respetando la legislación)

# Manual de Pocket Gone

El manual actualizado de Pocket Gone se encuentra en https://www.scribd.com/document/895676548/Manual-de-Pocket-Gone

# Diagnósticos Bluetooth

Para acceder al modo diagnóstico es necesario realizar el puente descripto en el manual y luego abrir Monitor Serial en 115200 baudios. Este modo estima los canales congestionados en la frecuencia de los parlantes Bluetooth, así como genera un listado de dispositivos en modo pair. Para acceder al modo diagnóstico es necesario tener un jumper cable conectado entre el pin D25 y GND.

# Monitor de funcionamiento

Para determinar si el software se encuentra cargado, el MAC autorizado, el módulo de Radiofrecuencia bien cableado y determinar si se reconocen las pulsaciones del botón abrir monitor serial en 115200 baudios.
